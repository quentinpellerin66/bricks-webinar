🔗 Connexion Google Sheets
Les données seront synchronisées en temps réel dans ton Google Sheet.
1. Ouvre Google Sheets → crée un nouveau classeur
2. Menu Extensions → Apps Script
3. Colle le code du fichier bricks-apps-script.js
4. Déployer → Nouveau déploiement → Type : Application Web
    Accès : Tout le monde → Autorise l'accès
5. Copie l'URL de déploiement ci-dessous
